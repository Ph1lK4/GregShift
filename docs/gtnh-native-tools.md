# GTNH 原生工具与在线阅读器

“GTNH 工具”独立于实例，无需先创建实例。矿物处理正则生成器、神秘时代研究助手使用 C# 本地计算；GTNH 种子地图、在线魔导手册使用受限内置浏览器。原有流程图、在线任务书、产线规划器保留。

## 数据来源及边界

原生工具内置 2026-11-22 读取的声明式数据，不执行或分发原站 JavaScript，不打包原站图标。

- 矿物路线：GTNH 中文维基 `Data:矿物处理正则表达式生成器.tabx`，修订 1068974，作者钛管道，表格明确标为 CC0。适用 GTNH 2.9.0-RC-1。原表空路线使用用户默认路线，`None` 表示不处理。争议项必须自行核对。补充冰矿已包含在路线快照中（补充表修订 1068975）。
- 地质前缀：`Data:矿物处理正则表达式生成器/地质变种.tabx`，修订 1067841，CC0，仅收录名称与前缀，没有复制图片。
- 中文要素名、默认权重：`Data:神秘时代研究助手.tabx`，修订 685223，作者 Youkoaona，CC0。默认权重不代表所有阶段的最优成本，可自行修改。
- 要素两两合成的事实关系核对于 `零件:神秘时代研究助手.js` 修订 751051；仅重新整理游戏的名称、两项组分事实，不分发其程序、文案、样式或图标。路径搜索独立实现。

来源页面均位于 `https://gtnh.huijiwiki.com/wiki/` 下。CC0 声明：`https://creativecommons.org/publicdomain/zero/1.0/`。数据的来源说明不将其他维基页面、图标或原站脚本改授权为 GPL。

过滤表达式仅匹配所选矿辞，不把数据当正则脚本执行。256/1024 字符限制对应过滤卡版本，选择旧版上限不代表内置 2.9.0 矿物数据已变成旧版数据。结果需结合实际 NEI 配方核对。

研究助手只求两要素之间的连接链，不求解整张研究笔记，也不同步研究进度。最少中间数为 0 时至少连接一步；允许重复要素以满足长度。加权距离为每条边两端权重之和。

种子地图由 `https://chunkbasenh.beyomoes.com/` 提供；魔导手册来自维基 `研究#研究一览`。页面仍需联网，内容和兼容性由原站维护。只开放明确站点的 HTTPS 导航，不给网页账号令牌、本地服务或游戏目录权限；下载、弹窗、设备权限仍按浏览器组件的原有限制处理。不会自动读取存档种子或上传文件。导出/读取 level.dat 并非本轮交付范围。

魔导手册加载完成后只展示原站的研究目录和交互研究图，隐藏网站导航、正文等外围区域。保留原组件的搜索、分类、缩放、研究节点详情和来源署名；不下载或重新打包原站脚本、图片。如果站点要求验证或研究组件未就绪，会保留原页面并提示重新加载，不隐藏验证界面。精简仅作用于维基的“研究”页，不影响其他工具或研究详情链接打开的页面。

## 本地设置

两项原生工具可显式保存和导入/导出方案，设置放在 GregShift 的工具数据目录，不写入实例；写入失败保留当前输入并显示原因。更新内置快照不会静默下载或覆盖用户设置，未知的新旧数据项按设置版本兼容规则处理。
