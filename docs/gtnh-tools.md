# GTNH 工具

更新日期：2026-11-22。以下介绍当前源码，已发布的 RC2 包不一定包含此功能。

左侧“GTNH 专区”正下方的 **“GTNH 工具”** 是独立页面。目录提供七项工具：工艺流程图、在线任务书、产线规划器、矿物处理正则、神秘时代研究助手、种子地图和在线魔导手册。点击卡片进入独立页面，不需要先选择实例，也不会因实例下载或游戏运行而禁用。新增原生工具的操作、数据来源及适用范围见[原生工具说明](gtnh-native-tools.md)。

## 流程图目录与详情

流程图以宽列表展示名称、分类和创建状态，可按名称搜索或按目录分类筛选。点击条目进入独立详情，返回目录时保留筛选条件和滚动位置。首次进入仅使用内置目录，不批量下载所有图表。

未创建的条目保留名称和目录位置，打开后显示“未创建，等待更新”，不会进入维基创建或编辑页。内置快照只保证可浏览目录，不代表所有图表已下载；点击“更新目录”才通过原站更新当前会话的名称和创建状态。更新失败保留已有目录，不把解析失败当成图表尚未创建。

原目录：[GTNH 中文维基：模板 FlowChart](https://gtnh.huijiwiki.com/wiki/%E6%A8%A1%E6%9D%BF:FlowChart)。

## 本机交互画布

已创建的图表在打开详情时按需读取原站公开页面中的声明式 JSON，由启动器自己的 WPF 画布绘制节点和连线，不只是截图或整页网站嵌入。只解析经过结构与大小限制验证的数据，不执行远端 Lua、JavaScript 或维基模板源码。

- 滚轮或“− / +”缩放，拖动平移，“适应窗口”显示整张图。
- 按分组高亮相关节点和路线；原站提供英文数据时可切换 English。
- 材料节点按原站节点 ID 显示物品图标，原站提供横向动态图集时播放对应帧；读取失败仍显示名称。
- 悬停机器或用键盘选择后按回车可查看本地配方卡片。卡片保留原站槽位布局、物品名称、数量、流体体积及耗时/耗电文字；不根据图表连线推算配方。原站未提供的详情会明确提示。
- 配方内的材质与材料选项仅在卡片可见时轮换；加工进度是阅读动画，不是游戏运行进度。关闭系统动画或使用高对比度时静态显示。
- “查看图表数据”显示只读 JSON，供查看或复制；它不是完整的原站模板、Lua 模块或可在本机执行的程序。
- 画布可用键盘操作：加减键缩放，`0` 恢复标准大小，`Home` 适应窗口，方向键平移，`F6` / `Shift+F6` 选择节点，回车查看节点提示。

当前实现不复制原站绘图程序，也不承诺完整还原所有原站交互或配方数据库。配方只来自该图表页面已有的详情，可能与实际游玩的整合包版本不同，请以游戏内配方为准。遇到不支持的结构、验证页面或网络错误，会明确显示原因；可重试，或显式选择“在此页查看原站”，仍在启动器内阅读。不会根据连线虚构缺失的数据。

原站可能以 HTTP 403 拒绝直接请求。此时启动器自动在内嵌浏览器中加载对应的正常原站页面，加载成功后自动读取图表数据并返回本机画布，无需先手动点开原站再读取。已有缓存仍会保留。若原站仍要求人工验证、数据尚未出现或缺少浏览器运行时，会保留原站页面或明确错误；请自行完成验证后点击“读取为本地图表”，或按提示安装运行时后重试，不会反复自动请求。

启动器只从当前已确认的图表页固定数据元素读取 JSON 与修订号，再使用相同的结构、大小和来源校验保存到本地图表缓存；不会执行 JSON 中的内容，也不把访问失败或验证页面当成有效图表。页面切换后的迟到结果不会导入到新的阅读页面。备用读取需要内嵌浏览器及网络，不绕过原站访问限制。内嵌原站本身仍会按正常浏览器行为运行自己的脚本，与本机画布只解析数据的行为不同。

## 缓存、更新与离线阅读

成功读取的图表以 JSON 保存在启动器数据根目录的 `cache/gtnh-tools/flowcharts/`，按来源地址生成文件名。缓存保存图表、配方、图片来源地址、原站修订号（原站提供时）、读取时间和许可标记，不保存网页脚本、账号或游戏数据。图片从原站指定的 `huiji-public.huijistatic.com` / `huiji-thumb.huijistatic.com` 图片目录按需获取，独立缓存；请求不携带浏览器 Cookie 或微软凭据。详情显示缓存来源和时间，“来源与署名”可查看原页面、贡献者历史及许可入口。

下次打开优先使用有效缓存，因此已缓存图表可离线阅读，也不需要 WebView2。“检查更新”才主动向原站获取新数据；更新失败时继续保留有效旧副本并提示原因。首次读取、缓存丢失或缓存无效时仍需联网。缓存写入失败会说明本次未能保存离线副本，不把“已显示”当成“已缓存”。

旧版只有文字的缓存仍可打开，点击“检查更新”后才补充当前页面的图标和配方。图片缓存缺失或下载失败不会使整张图失效。图片请求限制域名、路径、PNG 类型、字节、像素和帧数，不跟随外部重定向；仅本机缓存，不将原站素材随发布包预装。

这不是全量离线资料包，也不自动追踪原站每次修订。清除上述目录会失去相应离线图表，下次需重新读取。目录快照与图表正文缓存是不同内容；更新目录需要内嵌网页及 WebView2。

缓存数据、原站署名及内容许可与启动器的 **GPL-3.0-or-later** 源码许可分开；启动器开源不改变图表的原始许可。图表详情保留原页面和贡献历史入口及读取时的许可标记。需要改编、打包或再分发图表时，应进一步核对具体来源与授权，不能据此说明推定任何用途都已获许可。当前不将全站图表、原站脚本和图标随发布包预装，也不作法律合规保证。

## 在线任务书

任务书继续使用独立的内嵌网页阅读区域，保留站点自身的版本选择、搜索和任务说明。它是在线资料，不读取实例中的任务进度，也不把网页进度同步回游戏。当前不依据所选实例自动切换任务书版本，请在网页中核对版本。

来源：[GTNH 在线任务书](https://gtnhquestsbook.top/)。启动器不保证第三方站点始终在线或每个版本的资料完整，网页不等于离线任务书。

## 网页阅读与 WebView2

在线任务书、目录联网更新和查看原站使用内嵌阅读器，提供返回、前进和重新加载。任务书不显示网页地址和复制链接按钮；目录及流程图原站阅读仍提供地址与复制功能。网络错误、浏览器进程异常或证书验证失败会显示原因并保留当前选择，便于重试。外部网页保持自己的配色，不强制注入启动器主题；规划器另有下述中文文字适配。

顶层网页只允许指定的 HTTPS 站点：阅读器按当前工具绑定 `gtnh.huijiwiki.com`、`gtnhquestsbook.top` 或 `chunkbasenh.beyomoes.com`，规划器独立使用 `gtnhplanner.com`。不同主机的工具不能相互导航。站外跳转、弹窗、网页直接下载和网站权限请求默认被阻止；规划器仅通过启动器的“导入方案 / 导出方案”提供受控 JSON 文件操作，不放开任意网页下载。需要其他来源或原站图片导出功能时，可在系统浏览器自行打开相应项目。网页没有读取启动器账号、实例文件或执行本机命令的宿主接口，也不忽略证书错误。本地图表的数据请求不使用浏览器 Cookie 或微软登录凭据。

内嵌网页需要 **Microsoft Edge WebView2 Evergreen Runtime**，与发布包附带的 .NET 不同。缺少它时工具页提示安装，不自动运行安装程序；本地图表、实例导入和启动等其他功能仍可使用。请从 [Microsoft 官方 WebView2 页面](https://developer.microsoft.com/microsoft-edge/webview2/) 获取。

浏览器只在用户明确请求网页时初始化，使用独立的 `cache/gtnh-tools/webview2/` 配置目录保存 Cookie、网页缓存和网站存储，不复用系统浏览器或微软正版登录配置。原站网页仍会执行自己的脚本并访问其内容服务，适用网站自身的隐私政策；这与本地图表只解析数据的行为不同。

清理任一工具缓存前先关闭启动器，核对目录后只删除需要清理的 `flowcharts/` 或 `webview2/`，不要误删实例、迁移备份、下载原包或微软账号凭证。详见[隐私说明](../PRIVACY.md)和[卸载说明](uninstall.md)。

## 产线规划器

“GTNH 工具”的第三个入口 **“产线规划器”** 在启动器内打开 [GTNH Planner](https://gtnhplanner.com/)。它用于选择物品和配方、布置产线及查看原站计算结果，不需要绑定实例，也不会读取游戏存档或自动把方案写入游戏。首次选择此入口才连接网站；切换工具后保留已打开的规划器与方案。

### 中文显示与搜索

- “中文显示”默认开启，可随时切回原文。它只改变已识别的界面文字、物品与机器名称，不改物品 ID、配方数值、方案名称、用户注释或输入内容。未收录文字保留英文。
- 中文搜索请使用页面上方标有 **“中文物品搜索 · 请在这里输入”** 的启动器搜索框；下方网页自己的搜索框仍使用英文。在上方输入中文或英文，从候选列表选择 **“中文名 · 英文原名”**，再点“搜索物品”。启动器将所选英文原名填入原站物品搜索，不根据中文同名项猜测唯一物品。未收录名称可直接用英文搜索。再次编辑搜索文字会解除旧选择并更新候选，不会继续使用上一次的物品。
- 中文词典来自社区 `gtnh-planner-zh`，包含 32,120 个名称，并补充了部分当前界面用语。词典与网站版本可能不同，译名也可能不完整或不准确；配方及物品含义请以所玩 GTNH 版本和原文为准。上方“来源与说明”可查看来源及本机数据目录。

### 保存、导入与导出

原站的方案与网站设置保存在启动器数据根目录的 **`cache/gtnh-tools/planner-webview2/`**，与其他工具网页、系统浏览器及微软账号配置分开。目录名称含 `cache`，但这里包含玩家创建的方案，**不能当作可随意清理的下载缓存**。关闭启动器或切换工具不会主动清空它；跨电脑迁移、重装、清理目录前请先逐个导出重要方案。

1. 点“导出方案”，由原站生成当前方案 JSON，经启动器校验后选择保存位置。取消文件选择不会移除原方案；已有文件只有在保存对话框中确认覆盖后才替换。
2. 点“导入方案”选择原站格式的 JSON。导入会新建一个方案标签，不覆盖已有方案；失败会保留原有方案并显示原因及可复制的相关路径。
3. 当前只接受 UTF-8、`schemaVersion: 1` 的方案文件，最大 **10 MiB**，并限制结构深度及各已知数组项数。启动器检查传输边界，原站导入器仍负责完整格式和配方兼容性；不是任意 JSON 都可导入。

导入的 JSON 会进入第三方规划器网页的运行环境，和直接在原站导入一样可由该站脚本处理。不要在方案名、注释或文件中存放密码、令牌等私人信息。文件操作需要用户主动点击并选择路径，网页不能自行访问本机任意文件；普通网页下载仍被阻止。

### 在线与版本边界

这是 **在线规划器，不是完整离线部署**。网页、配方、图标和计算功能由原站提供；本机保留方案不代表断网时所有功能都能使用。原站更新、网络故障或页面结构变化可能影响中文适配、搜索及文件操作，届时可关闭中文显示、刷新后重试，或在系统浏览器访问原站。社区数据库与登录等服务可能单独不可用，当前不保证社区登录或云同步，也不依据实例自动匹配配方版本。

集成方式、固定参考版本和许可见[规划器来源与许可说明](gtnh-planner-notices.md)。启动器未预装整站程序、配方库或图标素材；网页内容、中文词典与启动器源码分别适用各自许可。

## 发布与开发检查

规划器的传输与中文搜索资源由自动化测试覆盖。若本机已安装 Node.js，还可在仓库根目录运行 `node tools/Test-GtnhPlanner.cjs`，检查受控 DOM 下的导入、导出、取消、超时和迟到结果隔离；该脚本不联网，也不读取玩家数据。它不能替代真实 WebView2 和在线站点的交互验收。

发布包只携带 WebView2 的 SDK 程序集及 Windows x64 原生加载器，不附带整个 Evergreen 浏览器运行时。加载器位于 `app/WebView2Loader.dll`，由 .NET 的 win-x64 发布资产提供；不要单独移动这些程序文件。

`tools/Build-Release.ps1` 从固定 NuGet 依赖收集 `LICENSE-WEBVIEW2.txt` 和上游声明，并附带规划器来源说明和中文词典的 `LICENSE-GTNH-PLANNER-ZH.txt`；制包白名单只允许上述确切加载器位置，不允许把图表缓存、运行缓存或用户浏览器配置打包。CI 也检查三个浏览器必需程序集/加载器是否存在。流程图缓存仅在用户按需读取后产生，规划器个人方案不会进入发布包。
